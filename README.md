# Minimal Wi-Fi over LoRa — Linux Server

> Этот репозиторий содержит серверную часть проекта **Minimal Wi-Fi over LoRa** и является лишь одним из компонентов общей системы. Описание архитектуры, протокола и остальных компонентов находится в [основном репозитории](https://github.com/paranoik1/Minimal_Wi-Fi_over_Lora).

Linux Server отвечает за приём и обработку пакетов от клиентских устройств, подготовку ответных данных и их отправку обратно через LoRa.

## Реализовано

- **Административный сайт** — регистрация и управление пользователями сети.
- **Проверка пакетов** — проверка контрольных сумм и обнаружение дубликатов.
- **Обработка разных типов пакетов** — реализована обработка `RECEIVED_PACKETS_REPORT` и `MSG_REQUEST`.
- **Получение и обработка веб-страниц** — скачивание веб-страниц, извлечение основного содержимого и конвертация результата в Markdown с удалением избыточной информации с помощью trafilatura.
- **Сжатие и распаковка данных** — подготовка полезной нагрузки для передачи по ограниченному радиоканалу.
- **Отправка данных** - отправка данных, записывая пакет по UART в LoRa модуль
- **Многопоточность** — для каждой пользовательской сессии создаётся отдельный поток.

## Roadmap

- [ ] **Проверка `user_id`** — проверка принадлежности отправителя к зарегистрированным пользователям сети через базу данных.
- [ ] **Шифрование данных** — шифрование и расшифровка полезной нагрузки с использованием индивидуального ключа пользователя. Ключи уже сохраняются в базе данных и связаны с соответствующими `user_id`. (временно реализовано в виде заглушки - возвращается тот же payload с функции `encrypt_payload` и `decrypt_payload`)
- [ ] **Защита от Replay-атак** — добавление `req_id` в структуру `Packet` и проверка повторного использования идентификаторов запросов.
- [ ] **Согласование параметров LoRa** — реализация механизма синхронизации с клиентом и согласования `Spreading Factor`, `Coding Rate` и `Bandwidth`.
